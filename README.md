# 维什戴尔·维维美 Codex 桌面宠物

仓库保留三个已经生成的 Codex v2 版本：

- 根目录：已推送的原始素材版（v2 repo-assets）
- [v3-2x-sharp](versions/weiweimei-v3-2x-sharp/)：2×重采样 + 轻锐化版
- [v4-uniform-rebuild](versions/weiweimei-v4-uniform-rebuild/)：从原始 GIF 重建、统一人物尺寸和脚底基线版

每个版本都包含 `pet.json`、无损 `spritesheet.webp`、PNG 备份和预览图。Codex 安装入口保持不变：`spriteVersionNumber: 2`、`spritesheetPath: spritesheet.webp`。

素材来源：[OTAXIO/digit_maid 维什戴尔皮肤素材](https://github.com/OTAXIO/digit_maid/tree/main/resource/wisdel/%E7%9A%AE%E8%82%A4%E7%B4%A0%E6%9D%90)。
