# 维什戴尔·维维美 Codex 桌面宠物

这是一个 Codex v2 animated pet 包，角色为《明日方舟》维什戴尔“维维美”皮肤的 Q 版桌面宠物。

## 文件

- `pet.json`：宠物元数据
- `spritesheet.webp`：Codex v2 主图集，8×11，`1536×2288`，RGBA
- `spritesheet.png`：无损 PNG 备份
- `preview-contact-sheet.png`：动作总览
- `preview-look-directions.png`：16 个朝向预览

## 素材来源

动作和角色分层素材主要来自 [OTAXIO/digit_maid 的维什戴尔皮肤素材](https://github.com/OTAXIO/digit_maid/tree/main/resource/wisdel/%E7%9A%AE%E8%82%A4%E7%B4%A0%E6%9D%90)。

本包保留原素材的黑色描边、灰白头发、红色饰物、橙色眼睛和黑红服装，并按 Codex v2 图集格式完成裁切与注册。
